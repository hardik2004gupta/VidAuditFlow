# Documentation Archive

This project was built in phases, each with a written brief and a summary of what shipped. Everything here is historical/reference material; the root [`README.md`](../README.md) is the current, living entry point for setup and architecture.

- **[`planning/`](planning/)** — the original modernization blueprint: target architecture, database/API design, UI vision, and the roadmap written before implementation began. Describes intent, not necessarily the exact final result.
- **[`audits/`](audits/)** — point-in-time engineering audits: [`PROJECT_AUDIT.md`](audits/PROJECT_AUDIT.md) (the original full-repository audit that kicked off the modernization) and [`PHASE_4_5_AUDIT.md`](audits/PHASE_4_5_AUDIT.md) (a mid-project audit before frontend work began). For the current state of the repository, see [`REPOSITORY_AUDIT.md`](../REPOSITORY_AUDIT.md) at the project root.
- **[`phases/`](phases/)** — one summary per implementation phase (`PHASE_2_SUMMARY.md` through `PHASE_8_SUMMARY.md`), each documenting what was actually built and verified, in order.
